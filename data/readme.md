# Billboard Hot 100 catalog

Source: `billboard_hot_100_spotify_audio_features_enriched.csv`, Kaggle
dataset `luthfimuthathohirin/billboard-hot-100-spotify-audio-features`.

The source is Billboard Hot 100 chart data, mostly US charting music from 1958
to 2026, enriched with Spotify audio features. `first_week` is a chart debut
date, not a release date. The app reads only its source allowlist; AI-generated
annotation columns are not used. Mood and era are derived by project code.

Citation: Muthathohirin, L., and Kaggle Automation Squad. (2026). *Billboard
Hot 100 & Spotify Audio Features: 68-Year Music Telemetry Benchmark*. Kaggle.
https://www.kaggle.com/datasets/luthfimuthathohirin/billboard-hot-100-spotify-audio-features
